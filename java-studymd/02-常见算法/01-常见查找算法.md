## 1. 常见查找算法

### 七种查找方式

2. 二分查找

### 数据是否需要有序？

| 查找方式 | 数据要求 |
| --- | --- |
| 基本查找 | 数据没有任何顺序也可以使用 |
| 二分查找、插值查找、斐波那契查找 | 数据一定要有顺序 |

## 使用案例：按员工编号查找员工

HR 系统中保存了一组**已经按升序排列**的员工编号，需要查找编号 `1008` 是否存在。

```java
int[] employeeIds = {1001, 1003, 1005, 1007, 1008, 1011, 1015, 1020};
int target = 1008;
```

数组有序，适合使用二分查找；如果逐个比较，基本查找最多需要比较 8 次，而二分查找每次排除一半范围。

### 二分查找的过程

1. 设定左边界 `left = 0`、右边界 `right = 7`。
2. 取中间位置：`mid = (left + right) / 2`。
3. 比较 `employeeIds[mid]` 和目标值：
   - 中间值比目标小：去右半边查找，`left = mid + 1`。
   - 中间值比目标大：去左半边查找，`right = mid - 1`。
   - 两者相等：查找成功。
4. 当 `left > right` 时，说明目标不存在。

本例查找过程：

| 轮次 | `left` | `right` | `mid` | 中间编号 | 结果 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 7 | 3 | 1007 | 小于 1008，查右半边 |
| 2 | 4 | 7 | 5 | 1011 | 大于 1008，查左半边 |
| 3 | 4 | 4 | 4 | 1008 | 查找成功 |

### Java 实现

```java
public class EmployeeSearch {
    public static int binarySearch(int[] employeeIds, int target) {
        int left = 0;
        int right = employeeIds.length - 1;

        while (left <= right) {
            int mid = (left + right) / 2;

            if (employeeIds[mid] == target) {
                return mid;
            } else if (employeeIds[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return -1;
    }

    public static void main(String[] args) {
        int[] employeeIds = {1001, 1003, 1005, 1007, 1008, 1011, 1015, 1020};
        int index = binarySearch(employeeIds, 1008);

        System.out.println(index); // 4
    }
}
```

### 算法解释

二分查找的核心是“每次比较后丢弃一半不可能的范围”。它速度快，但前提是数据有序；如果员工编号是乱序的，应使用基本查找，或先排序后再二分查找。
