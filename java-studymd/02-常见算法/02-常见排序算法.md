# 第二章：常见算法

## 2. 常见排序算法

常见排序算法包括：冒泡排序、选择排序、插入排序、归并排序和快速排序。

> 本笔记将“递归”按常见排序分类理解为“归并排序”，归并排序通常使用递归实现。

| 算法 | 核心思想 | 特点 |
| --- | --- | --- |
| 冒泡排序 | 相邻元素两两比较，大元素不断向后移动 | 易理解，效率较低 |
| 选择排序 | 每轮选择最小元素，放到未排序部分的开头 | 交换次数较少，效率较低 |
| 插入排序 | 将当前元素插入已排序部分的正确位置 | 适合数据量较小或基本有序的数据 |
| 归并排序 | 递归拆分为小数组，再将有序数组合并 | 效率稳定，需要额外空间 |
| 快速排序 | 选择基准值，将数据分到基准值两侧，再递归处理 | 平均效率高 |

## 使用案例：录入新成绩后排序

老师录入了一组学生成绩，需要按从低到高排序：

```java
int[] scores = {92, 76, 88, 95, 81};
```

这里使用**插入排序**。可以把前面已经排好的成绩看成一排有序队伍，每次取出一个新成绩，插入到它应在的位置。

### 插入排序过程

| 轮次 | 取出的成绩 | 排序后的前半部分 |
| --- | --- | --- |
| 初始 | 92 | `[92]` |
| 1 | 76 | `[76, 92]` |
| 2 | 88 | `[76, 88, 92]` |
| 3 | 95 | `[76, 88, 92, 95]` |
| 4 | 81 | `[76, 81, 88, 92, 95]` |

每一轮都执行三个动作：

1. 保存当前要插入的元素。
2. 将已排序部分中比它大的元素向右移动。
3. 将当前元素放入空出的位置。

### Java 实现

```java
public class ScoreSort {
    public static void insertionSort(int[] scores) {
        for (int i = 1; i < scores.length; i++) {
            int current = scores[i];
            int j = i - 1;

            while (j >= 0 && scores[j] > current) {
                scores[j + 1] = scores[j];
                j--;
            }

            scores[j + 1] = current;
        }
    }

    public static void main(String[] args) {
        int[] scores = {92, 76, 88, 95, 81};
        insertionSort(scores);

        for (int score : scores) {
            System.out.print(score + " ");
        }
        // 输出：76 81 88 92 95
    }
}
```

### 算法解释

插入排序不需要每次都重新比较全部元素，而是维护“左侧已排序、右侧待排序”的结构。当前成绩 `81` 插入时，`95`、`92`、`88` 依次右移，直到找到 `76` 后面的位置，再把 `81` 放进去。
