# 第六章：数据库 MySQL

## 1. MySQL 与关系模型

### MySQL 是什么

MySQL 是一种关系型数据库管理系统，用于持久化保存和管理数据。

**使用场景：**保存用户、商品、订单等业务数据，程序关闭后数据仍然存在。

### 关系型数据模型

关系型数据库通过多张相互关联的二维表组织数据。

- 表：一类数据，例如学生表。
- 行：一条记录，例如一个学生。
- 列：一种属性，例如姓名、年龄。
- 主键：唯一标识一行数据。
- 外键：建立两张表之间的关系。

**案例：学生与班级**

```text
class（班级表）             student（学生表）
id  name                   id  name  class_id
1   Java一班                101 张三   1
```

`student.class_id` 指向 `class.id`，表示张三属于 Java 一班。

**使用场景：**订单表通过用户编号关联用户表，避免在每条订单中重复保存完整用户信息。
