# 第三章：集合进阶

## 1. 单列、双列集合与迭代器

### 单列集合与双列集合

| 类型 | 顶层接口 | 数据形式 | 示例 |
| --- | --- | --- | --- |
| 单列集合 | `Collection` | 一次存储一个数据 | 学生姓名列表：`"脉动"`、`"康帅博"` |
| 双列集合 | `Map` | 一次存储一对键值（key-value）数据 | 商品价格：`"脉动" -> 5` |

### 单列集合体系

```text
Collection
├── List
│   ├── ArrayList
│   ├── LinkedList
│   └── Vector
└── Set
    ├── HashSet
    │   └── LinkedHashSet
    └── TreeSet
```

| 集合 | 元素特点 |
| --- | --- |
| `List` | 有序、可重复、有索引 |
| `Set` | 不可重复、无索引；遍历顺序取决于具体实现 |
| `HashSet` | 无序、不重复、无索引 |
| `LinkedHashSet` | 有序（保持添加顺序）、不重复、无索引 |
| `TreeSet` | 按规则排序、不重复、无索引 |

### `Collection` 的遍历方式

1. 迭代器遍历
2. 增强 `for` 遍历
3. Lambda 表达式遍历

## 迭代器遍历

迭代器遍历集合时不依赖索引，适用于 `Collection` 体系中的集合。

```java
Collection<String> list = new ArrayList<>();
list.add("三");
list.add("连");
list.add("外");

Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String str = it.next();
    System.out.println(str);
}
```

### 需要掌握的三个方法

| 方法 | 作用 |
| --- | --- |
| `iterator()` | 获取迭代器对象 |
| `hasNext()` | 判断当前位置是否还有元素 |
| `next()` | 获取当前元素，并将指针向后移动 |

### 迭代器使用细节

- 当前位置没有元素还调用 `next()`，会报 `NoSuchElementException`。
- 遍历结束后，迭代器指针不会复位；需要重新获取迭代器。
- 一个循环中只调用一次 `next()`，否则会跳过元素。
- 迭代器遍历时，不要使用集合自身的 `add()`、`remove()` 等方法修改集合；需要删除当前元素时，使用 `it.remove()`。

### 其他两种遍历写法

```java
// 增强 for
for (String str : list) {
    System.out.println(str);
}

// Lambda 表达式
list.forEach(str -> System.out.println(str));
```
