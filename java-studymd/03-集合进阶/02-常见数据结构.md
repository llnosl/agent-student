# 第三章：集合进阶

## 2. 数据结构与 Set 速记

> 本节先掌握“特点、场景、会使用”，底层源码后续再学。

### 常见数据结构

| 知识点 | 核心特点 | 使用场景 |
| --- | --- | --- |
| 栈 | 后进先出（LIFO） | 方法调用、撤销操作 |
| 队列 | 先进先出（FIFO） | 排队任务、消息处理 |
| 数组 | 连续存储，按索引查询快 | 数据量固定、频繁查询 |
| 链表 | 节点通过引用相连 | 频繁在首尾增删 |
| 二叉查找树 | 左小右大 | 保存可排序、需查找的数据 |
| 平衡二叉树 | 左右子树高度差受控，会旋转恢复平衡 | 避免普通二叉树退化成链表 |
| 红黑树 | 特殊的自平衡二叉查找树 | `TreeSet`、`TreeMap` 的底层排序结构 |

### 二叉查找树案例

依次放入 `5、3、7、4`：`3` 在 `5` 左边，`7` 在右边，`4` 在 `3` 右边。中序遍历得到 `3、4、5、7`。

### HashSet、LinkedHashSet、TreeSet

三者都用于保存**不重复元素**。

| 集合 | 顺序 | 使用场景 |
| --- | --- | --- |
| `HashSet` | 无序 | 只需去重，通常优先使用 |
| `LinkedHashSet` | 保持添加顺序 | 去重后仍需原顺序 |
| `TreeSet` | 按规则排序 | 去重并排序 |

#### 案例：名单去重

```java
Set<String> names = new HashSet<>();
names.add("张三");
names.add("李四");
names.add("张三");
System.out.println(names.size()); // 2
```

自定义对象放入 `HashSet` 时，应重写 `equals()` 和 `hashCode()`，否则内容相同的对象可能无法去重。

#### 案例：成绩排序

```java
Set<Integer> scores = new TreeSet<>();
scores.add(90);
scores.add(70);
scores.add(80);
System.out.println(scores); // [70, 80, 90]
```

自定义对象排序有两种方式：实现 `Comparable`（默认规则），或创建集合时传入 `Comparator`（临时规则）。

```java
Set<String> words = new TreeSet<>((a, b) -> a.length() - b.length());
```

> 暂记：`HashSet` 底层依赖 `HashMap`；`TreeSet` 底层依赖红黑树。旋转、红黑规则和源码实现后续专题学习。
