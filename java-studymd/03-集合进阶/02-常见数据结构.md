# 第三章：集合进阶

## 2. 常见数据结构

学习一种数据结构时，重点关注三个问题：

1. 数据结构长什么样子？
2. 如何添加数据？
3. 如何删除数据？

### 常见数据结构

| 数据结构 | 核心特点 |
| --- | --- |
| 栈 | 后进先出（LIFO） |
| 队列 | 先进先出（FIFO） |
| 数组 | 连续存储，通过索引访问元素 |
| 链表 | 节点通过引用连接，便于在已知位置增删 |
| 二叉树 | 每个节点最多有两个子节点 |
| 二叉查找树 | 左子树节点小于根节点，右子树节点大于根节点 |
| 平衡二叉树 | 通过控制树高，避免树过度倾斜 |
| 红黑树 | 一种自平衡二叉查找树，常用于提高查找、添加和删除效率 |
