# 第三章：集合进阶

## 3. 泛型深入

### 什么是泛型？

泛型是 JDK 5 引入的特性，用于在**编译阶段**约束并检查操作的数据类型。

```java
List<String> names = new ArrayList<>();
names.add("张三");
// names.add(100); // 编译错误
```

### 泛型的好处

- 统一数据类型。
- 将原本可能在运行期发生的类型转换问题提前到编译期发现。
- 读取数据时不需要手动强制类型转换。

### 泛型的细节

- 泛型中不能写基本数据类型，应使用包装类，例如 `Integer`、`Double`。
- 指定 `List<Animal>` 后，可以添加 `Animal` 对象及其子类对象。
- 不写泛型时使用的是原始类型，元素按 `Object` 处理，容易出现类型转换问题。
- Java 泛型是伪泛型：编译后会发生**类型擦除**，泛型类型信息主要用于编译期检查。

```java
// 推荐：类型明确
ArrayList<String> list = new ArrayList<>();

// 不推荐：原始类型，编译期无法限制元素类型
ArrayList rawList = new ArrayList();
```

### 泛型定义的位置

#### 泛型类

在类名后面定义泛型，创建对象时确定类型。

```java
public class Box<E> {
    private E value;

    public void setValue(E value) {
        this.value = value;
    }

    public E getValue() {
        return value;
    }
}

Box<String> box = new Box<>();
```

#### 泛型方法

在修饰符后面定义泛型，调用方法时确定类型。

```java
public static <E> void print(E value) {
    System.out.println(value);
}
```

#### 泛型接口

在接口名后面定义泛型，实现类确定类型，也可以继续定义泛型。

```java
public interface Data<E> {
    void add(E value);
}
```

### 泛型的继承

数据具有继承性，但泛型本身不具有继承性。

```java
class Animal {}
class Dog extends Animal {}

List<Dog> dogs = new ArrayList<>();
// List<Animal> animals = dogs; // 编译错误
```

虽然 `Dog` 是 `Animal` 的子类，但 `List<Dog>` 不是 `List<Animal>` 的子类。

### 通配符

| 写法 | 含义 | 常见操作 |
| --- | --- | --- |
| `<?>` | 类型不确定 | 可读取为 `Object`；不能添加非 `null` 数据 |
| `<? extends E>` | E 或 E 的子类 | 适合读取，不能添加非 `null` 数据 |
| `<? super E>` | E 或 E 的父类 | 适合添加 E 及其子类对象；读取时只能按 `Object` 看待 |

```java
// 接收 Animal 或 Animal 子类组成的列表，适合读取
public static void printAnimals(List<? extends Animal> list) {
    for (Animal animal : list) {
        System.out.println(animal);
    }
}

// 接收 Dog 或 Dog 父类组成的列表，适合添加 Dog
public static void addDog(List<? super Dog> list) {
    list.add(new Dog());
}
```

记忆：`extends` 用于“生产数据、读取数据”；`super` 用于“消费数据、添加数据”。

### 使用场景

- 定义类、方法、接口时，如果操作的数据类型暂时不确定，可以定义泛型。
- 如果类型不确定但能确定继承体系，可以使用通配符。
