## 笔记约定

- 章节目录使用两位数字编号，例如 `01-面向对象进阶`。
- 知识点文件按学习顺序编号，例如 `01-静态变量.md`。
- 笔记保持简短；每个知识点至少包含：核心概念、一个使用场景和一个最小案例。
- 暂时跳过的底层原理要明确标注，方便后续重新学习。
