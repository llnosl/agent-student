# 第一章：面向对象进阶

## 14. 内部类

### 内部类的分类

- 成员内部类
- 静态内部类
- 局部内部类
- 匿名内部类

### 成员内部类

写在成员位置、属于外部类成员的类，叫成员内部类。

获取成员内部类对象：

- 成员内部类被 `private` 修饰时：在外部类中编写方法，对外提供内部类对象。
- 成员内部类不是 `private` 时：直接创建对象。

```java
Outer.Inner oi = new Outer().new Inner();
```

外部类成员变量和内部类成员变量重名时，在内部类中使用 `Outer.this.变量名` 访问外部类成员变量：

```java
System.out.println(Outer.this.name);
```

### 局部内部类

- 将内部类定义在方法里面，就叫局部内部类，类似方法里的局部变量。
- 外界无法直接使用，需要在方法内部创建对象并使用。
- 局部内部类可以直接访问外部类成员，也可以访问方法内的局部变量。
