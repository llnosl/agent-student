# 第一章：面向对象进阶

## 4. 继承概述

### 什么是继承？有什么好处？

继承是面向对象三大特征之一，可以让类和类之间产生父子关系。

多个子类中重复的代码可以抽取到父类中，子类可以直接使用，从而减少代码冗余、提高代码复用性。

### 继承的格式

```java
public class 子类 extends 父类 {
}
```

### 继承后子类的特点

- 子类可以得到父类的属性和行为，并直接使用。
- 子类可以在父类的基础上新增其他功能，子类更强大。

### 继承的注意事项

1. Java 只能单继承：一个类只能继承一个直接父类。
2. Java 不支持多继承，但支持多层继承。
3. Java 中所有的类都直接或间接继承于 `Object` 类。

### 子类可以继承哪些内容？

| 父类内容 | 非 `private` | `private` |
| --- | --- | --- |
| 构造方法 | 不能继承 | 不能继承 |
| 成员变量 | 可以继承 | 可以继承，但不能直接访问 |
| 成员方法 | 可以继承 | 不能继承 |
