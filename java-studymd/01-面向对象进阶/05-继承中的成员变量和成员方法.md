# 第一章：面向对象进阶

## 5. 继承中的成员变量和成员方法

### 成员访问特点

- `this` 调用：遵循就近原则。
- `super` 调用：直接查找父类。

### 什么是方法重写？

在继承体系中，子类出现了和父类中一模一样的方法声明，我们就称子类的这个方法是重写的方法。

### `@Override` 注解

方法重写建议加上 `@Override` 注解：可以校验重写是否正确，同时可读性更好。

### 重写方法的基本要求

- 子类重写的方法应尽量和父类中的方法保持一致。
- 只有虚方法表里面的方法可以被重写。

### 方法重写的本质

覆盖虚方法表中的方法。
