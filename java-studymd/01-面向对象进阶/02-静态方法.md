# 第一章：面向对象进阶

## 2. 静态方法

在学习静态方法之前，先区分 Java 项目中常见的三类：**JavaBean 类、测试类和工具类**。

### 2.1 三种常见的类

#### 2.1.1 JavaBean 类

JavaBean 类用于**描述一类事物并封装它的数据**，例如学生、用户、商品和订单。

初学阶段常见的 JavaBean 类通常具有以下结构：

- 成员变量使用 `private` 修饰。
- 提供无参构造方法和带参构造方法。
- 提供成员变量对应的 `get`、`set` 方法。
- 根据需要提供其他与对象自身数据有关的实例方法。

```java
public class Student {
    private String name;
    private int age;

    public Student() {
    }

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }
}
```

> JavaBean 的重点是封装对象的数据。像 `name`、`age` 这样的数据属于具体学生，因此不能简单地全部定义为 `static`。

#### 2.1.2 测试类

测试类用于**创建对象、调用方法并观察运行结果**，帮助我们验证代码是否符合预期。

在当前学习阶段，测试类通常包含程序入口 `main` 方法：

```java
public class StudentTest {
    public static void main(String[] args) {
        Student student = new Student("小明", 18);

        System.out.println(student.getName());
        System.out.println(student.getAge());
    }
}
```

这里所说的测试类是用于练习和手动验证代码的类。以后还会接触使用 JUnit 等测试框架编写的自动化测试类。

#### 2.1.3 工具类

工具类用于**集中存放可重复使用的通用功能**，例如数组处理、字符串处理、日期处理和数学计算。

工具方法一般只根据调用者传入的参数完成计算，不依赖某个特定对象保存的数据。例如：

```java
public class ArrayUtils {
    public static int getMax(int[] arr) {
        int max = arr[0];

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }

        return max;
    }
}
```

调用工具方法时，可以直接写：

```java
int[] arr = {10, 30, 20};
int max = ArrayUtils.getMax(arr);
System.out.println(max); // 30
```

### 2.2 静态方法的定义

被 `static` 修饰的成员方法叫作**静态方法**，也叫**类方法**。

```java
public class Demo {
    public static void show() {
        System.out.println("这是一个静态方法");
    }
}
```

### 2.3 静态方法的特点

1. 静态方法属于类，而不属于某个对象。
2. 静态方法随着类的加载而存在。
3. 调用静态方法通常不需要创建对象。
4. 推荐使用“类名.方法名”的形式调用。

```java
Demo.show();
```

Java 允许通过对象名调用静态方法，但不推荐：

```java
Demo demo = new Demo();
demo.show(); // 可以运行，但不推荐
```

使用 `Demo.show()` 能清楚地表达：`show` 方法属于 `Demo` 类。

### 2.4 工具类和静态方法的关联

工具类中的方法通常定义为静态方法，因为这些方法一般：

- 只需要使用调用者传入的参数。
- 不需要读取或修改某个工具对象的实例变量。
- 没有必要为了调用一个通用功能而先创建工具对象。

如果工具方法不使用 `static`，每次调用前都需要创建对象：

```java
ArrayUtils utils = new ArrayUtils();
int max = utils.getMax(arr);
```

当工具方法使用 `static` 后，可以直接通过类名调用：

```java
int max = ArrayUtils.getMax(arr);
```

因此，典型工具类通常具有以下设计：

```java
public final class ArrayUtils {
    // 私有构造方法：防止外部创建没有意义的工具类对象
    private ArrayUtils() {
    }

    public static int getMax(int[] arr) {
        int max = arr[0];

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }

        return max;
    }

    public static int getMin(int[] arr) {
        int min = arr[0];

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < min) {
                min = arr[i];
            }
        }

        return min;
    }
}
```

这里有三个关键点：

- 工具方法使用 `public static`，外部可以直接通过类名调用。
- 构造方法使用 `private`，避免创建工具类对象。
- 工具类使用 `final`，表示不希望其他类继承它；这是常见写法，但不是语法上的强制要求。

> 工具方法通常是静态方法，但静态方法不一定都是工具方法。例如 `main` 方法是静态方法，却不是工具方法。

### 2.5 静态方法访问成员的规则

#### 静态方法只能直接访问静态成员

```java
public class Student {
    static String schoolName = "希望中学";
    String name = "小明";

    public static void printInfo() {
        System.out.println(schoolName); // 正确：静态方法访问静态变量
        // System.out.println(name);    // 错误：不能直接访问实例变量
    }
}
```

调用静态方法时可能还没有创建任何对象，因此 Java 不知道应该访问哪一个对象的 `name`。

如果确实需要访问实例成员，必须先获得一个明确的对象：

```java
public static void printStudentName(Student student) {
    System.out.println(student.name);
}
```

#### 实例方法可以直接访问静态成员和实例成员

```java
public class Student {
    static String schoolName = "希望中学";
    String name;

    public void printInfo() {
        System.out.println(name);       // 实例变量
        System.out.println(schoolName); // 静态变量
    }
}
```

#### 静态方法中没有 `this`

`this` 表示当前对象，而静态方法属于类，调用时可以没有当前对象，所以静态方法中不能使用 `this`。

```java
public static void show() {
    // System.out.println(this); // 编译错误
}
```

可以记为：

| 调用位置 | 可直接访问静态成员 | 可直接访问实例成员 | 能否使用 `this` |
| --- | --- | --- | --- |
| 静态方法 | 可以 | 不可以 | 不可以 |
| 实例方法 | 可以 | 可以 | 可以 |

### 2.6 静态方法与实例方法的区别

| 对比项 | 静态方法 | 实例方法 |
| --- | --- | --- |
| 修饰方式 | 使用 `static` 修饰 | 不使用 `static` 修饰 |
| 归属 | 属于类 | 属于对象 |
| 推荐调用方式 | `类名.方法名()` | `对象名.方法名()` |
| 是否需要对象 | 通常不需要 | 需要先创建对象 |
| 直接访问实例成员 | 不可以 | 可以 |
| 使用 `this` | 不可以 | 可以 |
| 常见用途 | 通用计算、工具方法、程序入口 | 操作某个对象自身的数据 |

判断一个方法是否应该使用 `static`，可以先问：

> 这个方法完成工作时，是否需要使用某个具体对象自身的数据？

- 不依赖具体对象，只根据参数完成通用功能：可以考虑静态方法。
- 需要读取或修改某个对象的实例变量：应该使用实例方法。

### 2.7 三类协作的完整示例

#### JavaBean 类：`Student.java`

```java
public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }
}
```

#### 工具类：`StudentUtils.java`

```java
public final class StudentUtils {
    private StudentUtils() {
    }

    public static Student getOlder(Student first, Student second) {
        if (first.getAge() >= second.getAge()) {
            return first;
        }

        return second;
    }
}
```

#### 测试类：`StudentTest.java`

```java
public class StudentTest {
    public static void main(String[] args) {
        Student student1 = new Student("小明", 18);
        Student student2 = new Student("小红", 20);

        Student older = StudentUtils.getOlder(student1, student2);
        System.out.println(older.getName()); // 小红
    }
}
```

三者的职责分别是：

| 类 | 职责 |
| --- | --- |
| `Student` | JavaBean 类，保存并描述学生数据 |
| `StudentUtils` | 工具类，通过静态方法提供通用功能 |
| `StudentTest` | 测试类，创建对象、调用代码并查看结果 |

### 2.8 常见误区

#### 误区一：静态方法可以直接访问所有成员

错误。静态方法只能直接访问静态成员，不能直接访问实例成员。

#### 误区二：所有方法都写成静态方法会更方便

虽然调用方便，但会模糊类和对象的职责。与具体对象状态有关的行为应当使用实例方法。

#### 误区三：工具类必须创建对象后才能使用

典型工具类的方法使用 `static` 修饰，可以直接通过类名调用；工具类的构造方法通常还会被私有化。

#### 误区四：所有静态方法都是工具方法

错误。`static` 只说明方法属于类。一个方法是不是工具方法，还要看它是否提供独立、通用、可复用的功能。

### 2.9 小练习

判断下面哪些代码可以通过编译：

```java
public class Demo {
    static int a = 10;
    int b = 20;

    public static void method1() {
        System.out.println(a); // ①
        System.out.println(b); // ②
    }

    public void method2() {
        System.out.println(a); // ③
        System.out.println(b); // ④
    }
}
```

<details>
<summary>查看答案</summary>

①、③、④可以通过编译，②不能通过编译。

`method1` 是静态方法，不能直接访问实例变量 `b`；`method2` 是实例方法，可以访问静态变量 `a` 和实例变量 `b`。

</details>

### 2.10 本节总结

> 静态方法属于类，推荐使用“类名.方法名”调用。工具类通常把通用方法定义为静态方法，并将构造方法私有化，从而让调用者不创建对象就能使用这些功能。静态方法只能直接访问静态成员，不能直接访问实例成员，也不能使用 `this`。
