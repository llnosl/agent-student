# 第一章：面向对象进阶

## 13. 接口

### 什么是接口？

接口代表规则，是对行为的抽象。想让哪个类拥有某种行为，就让该类实现对应的接口。

例如，动物类可以抽取“吃饭、喝水”等共性；“会游泳”不是所有动物都有的共性，可以定义为游泳接口，让青蛙、狗等会游泳的动物实现它。

### 基本格式

```java
public interface Swim {
    void swim();
}

public class Dog extends Animal implements Swim {
    @Override
    public void swim() {
        System.out.println("狗在游泳");
    }
}
```

- 类与接口之间使用 `implements`。
- 一个类可以实现多个接口。
- 实现类要么重写接口中的所有抽象方法，要么自身定义为抽象类。

### 接口多态

当方法参数是接口时，可以传递该接口所有实现类的对象。

```java
public static void letSwim(Swim animal) {
    animal.swim();
}

letSwim(new Dog());
```

这称为接口多态。

### 接口中的方法：JDK 版本变化

| JDK 版本 | 接口中允许的方法 |
| --- | --- |
| JDK 7 及以前 | 只能定义抽象方法 |
| JDK 8 | 可以定义默认方法和静态方法 |
| JDK 9 | 可以定义私有方法和私有静态方法 |

### JDK 8 默认方法

接口中可以使用 `default` 定义默认方法，用于解决接口升级的问题。

```java
public interface Swim {
    default void show() {
        System.out.println("这是默认方法");
    }
}
```

- 默认方法不是抽象方法，不强制实现类重写。
- 如果重写默认方法，重写时去掉 `default` 关键字。
- `public` 可以省略，`default` 不能省略。
- 一个类实现多个接口，若接口中存在同名默认方法，必须重写该方法。

### 接口与抽象类的区别

| 对比项 | 接口 | 抽象类 |
| --- | --- | --- |
| 核心作用 | 定义行为规则、能力 | 抽取同一体系的共性与状态 |
| 关系关键字 | `implements` | `extends` |
| 数量限制 | 一个类可以实现多个接口 | 一个类只能继承一个直接父类 |
| 构造方法 | 没有构造方法 | 可以有构造方法 |
| 成员变量 | 默认是 `public static final` 常量 | 可以定义普通成员变量 |
| 方法 | 以抽象方法为主；JDK 8+ 可有默认、静态方法 | 可以有抽象方法和普通方法 |
| 适用场景 | “具备某种能力”，如会游泳、会飞 | “属于同一类事物”，如动物、员工 |

> 记忆：抽象类解决“是什么”的共性；接口解决“能做什么”的规则。
