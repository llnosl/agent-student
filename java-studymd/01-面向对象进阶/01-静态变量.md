# 第一章：面向对象进阶

## 1. 静态变量

### 1.1 定义

被 `static` 修饰的成员变量叫作**静态变量**，也叫**类变量**。

```java
public class Student {
    // 静态变量：属于 Student 类
    static String schoolName = "希望中学";

    // 实例变量：属于每一个 Student 对象
    String name;
}
```

### 1.2 核心特点

1. **被该类的所有对象共享**

   静态变量只有一份。任意对象修改它，其他对象再次读取时都会得到修改后的值。

2. **属于类，不属于某个对象**

   即使还没有创建对象，也可以通过类名访问静态变量。

3. **随着类的加载而加载，优先于对象存在**

   Java 首次主动使用一个类时，会加载并初始化这个类的静态成员；创建对象必须发生在类加载之后。

### 1.3 调用方式

推荐使用“类名.静态变量名”的方式调用：

```java
System.out.println(Student.schoolName);
```

Java 也允许通过对象名调用静态变量，但不推荐：

```java
Student student = new Student();
System.out.println(student.schoolName); // 可以运行，但不推荐
```

使用类名调用能清楚地表达：这个变量属于类，并由该类的所有对象共享。

### 1.4 完整示例

```java
public class Student {
    static String schoolName = "希望中学";
    String name;

    public Student(String name) {
        this.name = name;
    }
}
```

```java
public class Test {
    public static void main(String[] args) {
        Student student1 = new Student("小明");
        Student student2 = new Student("小红");

        System.out.println(Student.schoolName); // 希望中学

        Student.schoolName = "阳光中学";

        System.out.println(Student.schoolName); // 阳光中学
        System.out.println(student1.schoolName); // 阳光中学，不推荐这样调用
        System.out.println(student2.schoolName); // 阳光中学，不推荐这样调用
    }
}
```

虽然示例中创建了两个 `Student` 对象，但 `schoolName` 只有一份，所以修改 `Student.schoolName` 后，两个对象看到的学校名称都会发生变化。

### 1.5 静态变量与实例变量的区别

| 对比项 | 静态变量（类变量） | 实例变量（成员变量） |
| --- | --- | --- |
| 修饰方式 | 使用 `static` 修饰 | 不使用 `static` 修饰 |
| 归属 | 属于类 | 属于对象 |
| 数量 | 一个类通常只有一份 | 每创建一个对象，就有一份 |
| 加载时机 | 随类的加载而加载 | 创建对象时产生 |
| 推荐调用方式 | `类名.变量名` | `对象名.变量名` |
| 适用数据 | 所有对象共享的数据 | 每个对象独有的数据 |

### 1.6 适用场景

当某个数据需要被一个类的所有对象共同使用时，可以将它定义为静态变量，例如：

- 学生共同所属的学校名称
- 系统的全局计数器
- 已创建对象的数量
- 配置项或公共状态

下面使用静态变量统计创建了多少个对象：

```java
public class Student {
    static int count = 0;

    public Student() {
        count++;
    }
}
```

```java
new Student();
new Student();
new Student();

System.out.println(Student.count); // 3
```

### 1.7 常见误区

#### 误区一：每个对象都有一份静态变量

错误。静态变量属于类，所有对象共享同一份数据。

#### 误区二：必须创建对象后才能访问静态变量

错误。可以直接使用 `类名.静态变量名` 访问，不需要先 `new` 对象。

#### 误区三：`static` 表示变量不能被修改

错误。`static` 表示变量属于类，不表示它不可修改。不可修改通常需要配合 `final`：

```java
public static final double PI = 3.1415926;
```

#### 误区四：通过对象调用时，访问的是对象自己的静态变量

错误。即使写成 `对象名.静态变量名`，访问的仍然是类所拥有的那一份静态变量。

### 1.8 注意事项

- 静态变量会长期跟随类存在，不要随意存放体积很大且不再使用的数据。
- 多线程同时修改同一个静态变量时，可能出现线程安全问题。
- 静态变量适合表达真正共享的数据，不要为了调用方便而把所有成员都写成 `static`。
- 常量通常使用 `public static final` 修饰，变量名使用全大写字母，单词之间用下划线连接。

### 1.9 小练习

阅读下面的代码，思考最终输出结果：

```java
public class User {
    static int onlineCount = 0;

    public User() {
        onlineCount++;
    }
}

public class Test {
    public static void main(String[] args) {
        User user1 = new User();
        User user2 = new User();

        user1.onlineCount = 10;

        System.out.println(user2.onlineCount);
        System.out.println(User.onlineCount);
    }
}
```

<details>
<summary>查看答案</summary>

两行都输出 `10`。`onlineCount` 是静态变量，`user1`、`user2` 和 `User` 访问的是同一份数据。

</details>

### 1.10 本节总结

> `static` 修饰的成员变量属于类，被该类的所有对象共享；它随着类的加载而加载，推荐使用“类名.静态变量名”的方式调用。
