# 第一章：面向对象进阶

## 7. 多态概述

### 什么是多态？

对象的多种形态。

### 多态的前提

- 有继承或实现关系。
- 有父类引用指向子类对象。
- 有方法的重写。

### 多态的好处

使用父类类型作为参数，可以接收所有子类对象，体现多态的扩展性与便利。

- 在多态形式下，右边对象可以实现解耦，便于扩展和维护。

```java
Person p = new Student();
p.work();
```

后续业务逻辑变化时，只需要更换右边创建的对象，后续调用代码通常无需修改。

### 多态的弊端

父类引用不能直接使用子类的特有功能。

### 引用数据类型的类型转换

- **自动类型转换（向上转型）**：子类对象赋值给父类引用。

  ```java
  Person p = new Student();
  ```

- **强制类型转换（向下转型）**：把父类引用转换为真正的子类类型。

  ```java
  Student s = (Student) p;
  ```

向下转型后可以调用子类特有功能；如果转换类型与真实对象类型不一致，会报错。转换前可使用 `instanceof` 判断：

```java
if (p instanceof Student) {
    Student s = (Student) p;
    s.study();
}
```
