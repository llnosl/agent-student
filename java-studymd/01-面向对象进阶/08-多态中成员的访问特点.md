# 第一章：面向对象进阶

## 8. 多态中成员的访问特点

- 调用成员变量：编译看左边，运行也看左边。
- 调用成员方法：编译看左边，运行看右边。

“左边”指父类引用类型，“右边”指实际创建的子类对象。

### 实际例子：宠物医院接诊狗

```java
class Animal {
    String name = "动物";

    void makeSound() {
        System.out.println("动物发出声音");
    }
}

class Dog extends Animal {
    String name = "狗";

    @Override
    void makeSound() {
        System.out.println("汪汪汪");
    }
}

public class PolymorphismDemo {
    public static void main(String[] args) {
        // 左边：Animal；右边：Dog
        Animal pet = new Dog();

        System.out.println(pet.name);
        pet.makeSound();
    }
}
```

运行结果：

```text
动物
汪汪汪
```

`pet.name` 调用的是左边 `Animal` 的成员变量；`pet.makeSound()` 在运行时调用右边 `Dog` 重写后的成员方法。
